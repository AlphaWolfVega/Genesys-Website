3 profils finaux

1. Tu as du mal à décoller en e-commerce. (stagnation actuelle)

2. Tu cherches un mentoring, mais c'est trop cher. (barrière financière)

3. Tu as déjà testé d'autres formations, mais tu as été déçu. (deuxième chance après échec)

Différence entre V5-A et V5-B

V5-A (Icônes logiques) :

· Courbe plate avec point = stagnation visuelle abstraite

· Étiquette de prix = code universel "ça coûte"

· Toque/diplôme de graduation = code universel "formation"

V5-B (Icônes concrètes) :

· Fusée stuck au sol = "ne décolle pas" littéralement

· Portefeuille = code universel "argent qui sort"

· Livre ouvert = code universel "j'ai étudié ça"

Mon vote : V5-A — la toque de graduation pour le profil 3 est plus immédiate que le livre (qui pourrait être confondu avec autre chose). L'étiquette de prix avec le petit cercle (point d'attache) est un code reconnu instantanément pour "prix" partout (e-commerce, retail, etc.).
