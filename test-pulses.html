Shimmer → Breath → Pulse → Breath → Loop

L'effet métallique passe, on respire, le pulse vient, on respire, on recommence. 6 variantes avec des timings différents — choisis celui qui a le bon rythme.

07-C1
Compact
Shimmer rapide, respirations courtes mais présentes. Le rythme reste vif.
4,5 s · 22% sh · 22% rest · 11% pulse · 45% rest
07-C2
Équilibré
Bon ratio. Le shimmer respire, le pulse arrive après une vraie pause.
5,5 s · 18% sh · 18% rest · 9% pulse · 55% rest
07-C3
Spacieux
Cycle plus long, plus apaisé. Chaque phase a sa place sans précipitation.
6,5 s · 15% sh · 17% rest · 10% pulse · 58% rest
07-C4
Long breath après shimmer
Grosse pause après le shimmer (35% du cycle) avant que le pulse arrive. Le bouton "se pose" longtemps.
5,5 s · 15% sh · 35% rest · 8% pulse · 42% rest
07-C5
Méditatif
Cycle très long. Les phases sont très étalées, l'oeil oublie presque entre deux apparitions.
7,5 s · 12% sh · 16% rest · 9% pulse · 63% rest
07-C6
Respirations symétriques
Les deux pauses ont la même durée. Sensation de cycle "carré", régulier.
5 s · 15% sh · 25% rest · 10% pulse · 50% rest
