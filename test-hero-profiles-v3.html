3 pictogrammes utilisés (instantanément reconnaissables)

Porte avec flèche → = changement de carrière, transition

Maison avec toit = revenu depuis chez toi

Courbe ascendante ↗ = scaling, faire décoller la boutique

Différences entre les 6 versions

V3-A (Cercle + chiffre) : icône en cercle doré + chiffre Playfair à droite. Combo riche.

V3-B (Icônes seules) : pictogramme dans un carré arrondi premium, sans chiffre. Plus épuré.

V3-C (Stack vertical) : icône au-dessus du chiffre, format colonne compact à gauche.

V3-D (Watermark) : chiffre 64px en filigrane derrière, icône + texte devant. Très visuel.

V3-E (Cards premium) : chaque profil dans une carte avec barre dorée à gauche + icône carrée + chiffre + texte.

V3-F (Badge) : icône en cercle + petit badge chiffre doré dans le coin. Style notification.

Mon vote : V3-A — combo le plus équilibré (icône reconnaissable + chiffre éditorial + lecture naturelle gauche-droite).
