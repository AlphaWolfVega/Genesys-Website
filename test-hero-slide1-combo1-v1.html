Récap des icônes proposées :

Set A — Symbolique : Fusée (mal à décoller) · Personne au carrefour 3 directions (seul face décisions) · Cercle avec point d'interrogation (doute identitaire).

Set B — Graphique : Courbe qui stagne (mal à décoller) · Silhouette isolée dans cercle pointillé (seul) · Visage avec point d'interrogation (doute).

Mon vote : Set A. La fusée est universellement comprise et masculine, le carrefour est immédiatement lisible, le "?" dans cercle est le standard pour le doute. Le Set B est plus subtil mais demande plus d'effort de lecture.
