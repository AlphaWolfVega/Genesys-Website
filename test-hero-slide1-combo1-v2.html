Récap des 4 sets :

Set 1 — Symbolique : Fusée · Personne au carrefour · Cercle interrogatif. Lecture immédiate, mass-market.

Set 2 — Business : Courbe plafond · Boussole orientée · Engrenage cassé. Langage entrepreneurial.

Set 3 — Humain : Grimpeur sous sommet · Silhouette dans bulle d'isolement · Personne avec ombre interrogative.

Set 4 — Métaphorique : Avion sur piste · Boussole déréglée · Miroir fissuré. Storytelling visuel.

Mon vote : Set 3 (Humain). La présence d'un personnage humain dans chaque icône crée un effet miroir physique avec le viewer ("je me vois là-dedans"). Set 1 est plus universel mais moins émotionnel.
